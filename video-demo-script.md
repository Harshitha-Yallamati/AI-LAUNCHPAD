# Three-minute demo script

0:00–0:25: Introduce the simulated goal: 500 unique workshop registrations in seven days with ₹2,000.

0:25–0:50: Open the landing page, submit a new registration, and show validation/referral attribution.

0:50–1:20: Open Dashboard and explain the goal progress, daily pace, channel allocation, and deterministic recommendations.

1:20–1:50: Open Ambassadors, create an ambassador, copy their referral link, and show active/inactive controls.

1:50–2:20: Use Registrations filters and export the displayed records to CSV.

2:20–2:40: Show Budget proposed versus actual spend and Analytics actual-versus-target charts.

2:40–3:00: Explain the trade-off: the submission uses local demo persistence because no Supabase credentials were supplied; production requires server-side auth, RLS, and deduplication.
