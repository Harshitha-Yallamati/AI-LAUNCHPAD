# AI learning notes

Use this as a truthful personal record when preparing the submission.

- Prompt used: describe the exact prompt or question you gave an AI tool.
- AI suggestion: record the proposal in your own words.
- Decision made: state whether it was accepted, adapted, or rejected.
- Change made: link the file or feature affected.
- Why: explain the product or engineering reasoning.
- Learning: write what you personally learned after validating the result.

Do not claim experiments, user research, or production results that did not occur.
